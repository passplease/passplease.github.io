在不久之前切换到Linux Mint之后，由于学习需要，我需要安装Matlab软件到电脑，可是在切换到Linux之前我就听说过Linux的依赖地狱问题，对于Matlab很不合理的安装方式，我害怕依赖地狱。同时因为Docker安装使用VNC会有输入法问题，VNC不能支持输入法，为此十分苦恼。为此我想考虑使用容器化软件安装方法，把Matlab安装到容器中，防止宿主机的依赖地狱问题。<br><br>
最终我听说了Distrobox这个工具可以把软件容器化安装，并且能提供类似原生应用的使用体验，我想会十分适合我，故而来尝试一下。<br><br>
在开始讲解之前先贴出官网[^official]
## 准备工作
首先需要检查宿主机环境，保证你可以无sudo使用docker或者podman，又或是lilipod，否则Distrobox不能运行。具体版本方面Distrobox还是很松的，基本上没问题，如果要看，官网[^official]也有，这里不赘述了。<br><br>
然后检查下面这些东西，这些东西关系到输入法能不能在Matlab中正常使用，使用如下命令
```shell
echo $XDG_SESSION_TYPE
```
这会确认电脑桌面是X11还是Wayland会话，两者在配置输入法的时候会有不同，这里我是X11会话。然后根据你想要安装的软件不同，需要不同的配置，因为不同的软件需要的配置还都不一样。所以这里我只能瞄准我的Matlab安装过程，其他软件我以后再补充。<br><br>
就Matlab，用的Java的XIM，我使用fcitx5，默认打开了的，然后检查
```bash
 xprop -root XIM_SERVERS
```
应该输出
```
XIM_SERVERS(STRING) = "fcitx"
```
这里我输出是（这里AI反复强调XIM 服务端的名字是 fcitx，不是 fcitx5，就是说fcitx5也不行）
```

```
有问题，实际上是`ibus`和`fcitx`环境变量配置问题，我已经习惯了，直接说我做了什么，因为具体都是干嘛的我也不知道，然后说在前面，最终配置是AI完成的（[建议跳转](#安装Distrobox)），后面只是记录我做过什么，记录命令可能有点用吧。

## 安装Distrobox
先去官网[^official]，并找到`Installation`，我们用curl安装最新版本，我也不在乎下载目录，我们live life dangerously，虽然官网有，不过我还是贴一个安装命令
```bash
curl -s https://raw.githubusercontent.com/89luca89/distrobox/main/install | sudo sh
```
## 使用
安装已经完成了，至于你的软件怎么安装、里面有什么，就都是Dockerfile需要关心的事情了，Distrobox做的就只是根据你的镜像管理一个容器，仅此而已。<br><br>
使用命令启动你的容器
```bash
distrobox create --image 镜像名 --name matlab
```
然后进入容器
```bash
distrobox enter matlab
```
进去之后你可以看到文件都是存在的，因为Distrobox会自动挂载整个$HOME，所以你的桌面是都有的。接下来输入
```bash
matlab -desktop
```
立刻，Matlab的桌面软件就弹出来了，使用完全和桌面应用一样，十分舒服，你想创建systemctl什么的也都随便你，完全没什么影响。
> 这个地方我必须提醒，对于我这种学生认证的用户，这个登录方法是不行的，原因在于这个方法需要下载离线的认证证书，而学生身份普遍需要学校服务器的验证转发，必须使用`-onlinelicensing`模式联网登录才是可以的，对应的命令是
> ```bash
> matlab -licmode onlinelicensing
> ```
> 反复重建中有一次我使用这个登录了，可是你多开一会还是会出许可证问题，然后退出。问题在于$HOME下Matlab文件出问题导致的，把他们都删掉就好了（我测试最终感觉就删除`.MATLABConnector`{: .filepath} 就可以了。

后面就打开使用就好了，也可以自己创建桌面快捷打开方式，都不影响
## 工作原理
这里主要关于Distrobox工作原理，关系到我们自己写Dockerfile安装软件的时候怎么做才能有前面`matlab -desktop`那样丝滑的体验。<br><br>
实际上这个很简单，实际上Matlab还是在容器内开的软件，只不过底层的X11流被换掉了，换成了你电脑上的X11流，其余流程实际上就和普通软件没什么区别，直接给X11说：“帮我开一个窗口，我展示这些东西”，然后X11就开了，仅此而已，如果我们自己做也只需要普通开虚拟桌面，然后用就可以了，没什么特别之处。
